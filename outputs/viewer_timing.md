# Viewer timing (browser)

Measured in the built-in browser pane with `performance.now()` around the page's own functions (script time, not paint), served by a local static server, at the time the viewer was built. These are hand-run measurements and are not regenerated by `refresh.sh`; the numbers shown on the page itself come from the same instrumentation.

- Load of indicators.json plus the 2020 tract GeoJSON: 50.2 ms in the last run (22 to 66 ms across runs).
- Change of indicator: median 3.0 ms, max 14.9 ms over 30 changes. First render after load: 12.9 to 20.1 ms.
- Switch of ACS period including map redraw: median 2.6 ms, max 3.8 ms (the first fetch of the 2010 tract file took 90.3 ms).
- Table sort: median 2.8 ms, max 4.7 ms over 25 sorts.
- Phone width check at 375 px: no horizontal page scroll; the table scrolls inside its own box.
